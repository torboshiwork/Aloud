Aloud — พูดแล้วให้ Mac พิมพ์ให้
────────────────────────────────────────────────

■ ติดตั้ง

1. ลาก Aloud ไปใส่โฟลเดอร์ Applications ในหน้าต่างนี้


■ เปิดครั้งแรก — สำคัญ อ่านก่อน

ดับเบิลคลิกแล้วจะขึ้นเตือนว่าเปิดไม่ได้ อันนี้ปกติ
แอปตัวนี้ยังไม่ได้ผ่าน notarization ของ Apple (ต้องเสียเงินปีละ $99)
ไม่ได้แปลว่ามีอะไรผิดปกติ

วิธีเปิด:
  1. ดับเบิลคลิก Aloud หนึ่งครั้ง (จะโดนเตือน กด OK ไปก่อน)
  2. เปิด System Settings → Privacy & Security
  3. เลื่อนลงมาจะเห็นข้อความพูดถึง Aloud → กดปุ่ม "Open Anyway"
  4. ยืนยันด้วยรหัสเครื่อง

ทำครั้งเดียวพอ ครั้งต่อไปเปิดได้ปกติ


■ ให้สิทธิ์ 2 อย่าง

System Settings → Privacy & Security →
  • Microphone    → เปิดให้ Aloud   (ไม่เปิด = ไม่ได้ยินเสียง)
  • Accessibility → เปิดให้ Aloud   (ไม่เปิด = ถอดเสียงได้แต่ไม่พิมพ์ออกมา)

ถ้าไม่เห็น Aloud ในลิสต์ Accessibility กดปุ่ม + แล้วเลือกจาก Applications


■ ใส่ API key ของตัวเอง

แอปใช้ Groq ถอดเสียง ต้องมี key ของตัวเอง (สมัครฟรี)

  1. เข้า https://console.groq.com  สมัคร แล้วสร้าง API key
  2. คลิกไอคอนไมค์บนแถบเมนูด้านบน → Settings…
  3. วาง key ลงไป → Save

key เก็บไว้ในเครื่องคุณเองที่ ~/.aloud/ ไม่ได้ส่งไปไหน


■ วิธีใช้

กด Fn ค้าง → พูด → ปล่อย
ข้อความจะพิมพ์ลงหน้าต่างที่เคอร์เซอร์อยู่ ใช้ได้ทุกแอป

เปลี่ยนปุ่ม เปลี่ยนภาษา เพิ่มคำศัพท์เฉพาะ ได้ในเมนู


■ ปัญหาที่เจอบ่อย

"No audio detected"
  → ถ้าใช้หูฟัง Bluetooth ลองสลับไปไมค์ปกติ
    หูฟัง Bluetooth บางรุ่นสลับโหมดแล้วไมค์หลุด

พิมพ์ไม่ออก แต่ไม่ error
  → ยังไม่ได้เปิด Accessibility

อยากดูว่าเกิดอะไรขึ้น
  → log อยู่ที่ ~/.aloud/debug.log (ไม่มีข้อความที่คุณพูดเก็บไว้)
